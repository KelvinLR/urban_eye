# ADR 0001: Record Architecture Decisions

## Status

Accepted

## Context

We need to record the architectural decisions made on this project.

## Decision

We will use Architecture Decision Records (ADRs) as described by Michael Nygard in his article "Documenting Architecture Decisions".

ADRs will be numbered sequentially and stored in `docs/adr/`.

## Consequences

- Architectural decisions will be documented and traceable.
- New team members can understand the rationale behind past decisions.
- Each ADR is immutable once accepted; superseding decisions create new ADRs.
